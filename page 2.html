Page 2: Features and Technologies

Main Features of the Website

1. Home Page: Introduces visitors to the website and explains its purpose.

2. About Us Page: Provides information about the brand, its aims, vision and mission.

3. My Profile Page: Allows users to enter, save, view and delete their names.

4. Navigation Menu: Helps users move between different pages.

5. Save Name Button: Stores the user's name in Local Storage.

6. Show Name Button: Displays the saved name.

7. Delete Name Button: Removes the saved name from Local Storage.

Technologies Used

HTML: Used to create the structure and content of the website.

CSS: Used to style the website and control its appearance.

JavaScript: Used to make the website interactive.

Local Storage: Used to save information in the browser.
